# 마법진 그리기 (RE:ROLL 미니게임)

마우스로 마법진을 똑같이 따라 그리는 1~5인 게임. 저주 슬롯머신이 방해하고, 정확할수록 마법이 발동합니다.

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코)
- 메인 게임 연동: `&embed=1` (결과 화면에서 멈춤) — `examples/host-example.html` 참고
- 시연/테스트: `&autoplay=1` (자동 그리기)

## 규칙
- 3라운드, 라운드마다 **슬롯머신**이 마법진(9종 중 난이도별)과 **저주**를 뽑음
  1. 연습 마법 (쉬운 모양, 저주 없음)
  2. 저주 라운드 (보통 모양 + 거울 저주 / 투명 잉크 / 흔들 종이 / 번개 마법 중 하나)
  3. **잭팟 라운드 ×2** (어려운 모양 + 기억 마법 / 거울 / 투명 / 흔들 중 하나)
- 저주
  - 기억 마법: 3초 뒤 안내선이 사라짐
  - 거울 저주: 펜이 좌우 반대로 (파란 십자가 실제 잉크 위치)
  - 투명 잉크: 내 선이 안 보임 (2초마다 살짝 비침), 마력 게이지도 ???
  - 흔들 종이: 종이가 이리저리 출렁임
  - 번개 마법: 5초만! 빨리 끝내기 보너스 2배
- 함께 하기: 마우스 하나를 차례로 넘김 → 다음 사람이 클릭(또는 Space)하면 시작
- 마우스 왼쪽 버튼을 누른 채 그리기 · 다 그리면 Space / Enter / 오른쪽 클릭 / '완료' 버튼
- 그리는 중: 선 위면 반짝이 + '좋아!/대단해!', 벗어나면 빨간 잉크 + 연기, 왼쪽 **마력 게이지** = 실시간 정확도
- 정확도 = 100 × 덮기 × (0.4 + 0.6 × 깔끔) / 일찍 끝내면 남은 초 × 2 (최대 +16, 정확도 50 이상일 때)
- 라운드 점수 = (정확도 + 보너스) × 배수. 최대 116 + 116 + 232 = 464점
- 80 이상 마법 발동 / 50 이상 그럭저럭 / 50 미만 펑!
- 라운드가 끝나면 **갤러리**: 모두의 그림을 나란히, 1등 왕관 · 꼴찌 '펑!'
- 합계 순위 → 메인 점수 10/7/5/3/1
- 개인 화면: 오늘 날짜 seed → 같은 날엔 모두 같은 마법진·저주. rankPoints=null, 진행자가 score 로 비교
- `&seed=숫자` 로 마법진·저주 순서 고정 가능

## 설정
`js/config.js` — 라운드 구성(난이도·저주 후보·배수), 저주 이름/설명, 그리기 시간, 붓 굵기, 채점 기준, 순위 점수.
모양은 `js/shapes.js` 의 `SHAPES` 에 60×60 좌표 + tier(easy/mid/hard) 로 추가.

## 파일
- js/config.js 설정 · js/shapes.js 마법진 모양+안내선 · js/sketch.js 종이/채점/자동 그리기
- js/input.js 키보드+마우스(포인터) · js/scenes/title|play|result.js 화면
- js/minigame-api.js 결과 전송 (postMessage / CustomEvent / window.RE_MINIGAME_LAST_RESULT)
- M: 소리 켜기/끄기

## 이번 손질
- 아래 안내 문구가 잘리던 것 수정 ("누른 채 그리기 · 다 그렸으면 완료 →")
- 라운드 슬롯머신: 마법진 미리보기를 끊김 없는 실선으로, 뒤 화면은 어둡게 덮어서 안 비침
- 잉크 색: 선 위 = 검정 · 벗어나면 **밝은 빨강** (한눈에 구분)
- 마력 게이지: 발동 기준선에 '80' · '발동' 표시
- 그리는 동안 캐릭터: 지팡이 끝 반짝이, 잘 그리면 통통 신남, 못 그리면 땀
- 마법 발동: 종이 뒤 빛줄기 + 모양별 아이콘이 터짐 (고리=달 · 별=별 · 하트=하트 · 번개=번개 · 다이아/왕관=보석 · 물고기=금화 · 소용돌이=소용돌이), 실패하면 큰 '펑!' + 연기
- 개인 화면 점수판: 라운드별 '내 기록' (모양 미리보기 · 점수 · 합계)
- 타이틀: 모양 이름이 종이 테두리에 안 걸치게, ◀ ▶ 간격을 글자에 맞춤
- 결과: 칸 이름 간격 넓힘, 사람이 적으면 표를 가운데로
- 진행 빠르게: 채점 · 갤러리 · 슬롯머신 시간을 줄이고 클릭하면 바로 넘어감
