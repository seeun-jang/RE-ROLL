# 실거리 사격 (RE:ROLL 미니게임)

군대 **실거리 사격장(자동 표적)** 을 모티브로 한 5사로 동시 사격. 100 · 200 · 250m 에서 올라오는 표적 20개를 실탄 20발로!

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코, 나머지 4사로는 CPU)
  - 개인 화면에서는 내 사로가 2배로 크게, CPU 4사로는 오른쪽에 좁게
- 메인 게임 연동: `&embed=1` (결과 화면에서 멈춤) — `examples/host-example.html`
- 시연/테스트: `&autoplay=1`

## 조작 (플레이어마다 5키 — 방향키 모양 4개 + 발사 키, 화면에 항상 표시)
| 사수 | 발사 | ↑ | ← | ↓ | → |
|---|---|---|---|---|---|
| 럼블 (1사로) | Q | W | A | S | D |
| 나르 (2사로) | R | T | F | G | H |
| 꽥스 (3사로) | U | I | J | K | L |
| 볼리베어 (4사로) | / | ↑ | ← | ↓ | → |
| 에코 (5사로) | 숫자패드 0 | 숫자패드 8 | 숫자패드 4 | 숫자패드 5 (또는 2) | 숫자패드 6 |
- 방향키 4개: 조준점(가늠쇠 끝)을 움직임. 놓으면 그 자리에 멈춤
- 발사 키(화면에서 빨간 키): 누르는 순간 격발
- 조준점은 숨 쉴 때마다 살짝 흔들림. **가만히 조준하고 있으면(약 0.7초) 숨이 골라져서 덜 흔들림**
- 쏘면 반동으로 조준점이 튀었다가 제자리로 돌아옴
- 개인 화면: 방향키 또는 WASD + Space(또는 Enter) 발사 / P 일시정지 · M 소리

## 사격장 고증
- 통제관 방송: 사수 준비 → 탄알집 결합 → 조정간 단발 → 준비된 사수부터 사격 개시 → (절반) 탄알집 교체 후 계속 사격 → 사격 끝 → 조정간 안전, 탄알집 제거
- 거리별 흙둑 뒤에서 상반신 표적이 올라옴 (100m 크고 낮게 · 250m 작고 높게), 맞으면 넘어감
- 실탄 20발 = 탄알집 10발 × 2. 10발을 다 쓰면 탄알집 교체 (그동안 못 쏨). 빗나가서 더 쏘면 뒤에 탄이 모자람
- 모래주머니 사대 · 사로 번호 · 거리 표지판 · 탄피 튐 · 총구 불꽃

## 점수 · 등급
- 명중 1발 10점 + 표적이 다 올라오고 빨리 맞힐수록 보너스 (최대 +5) → 만점 300
- 등급 (명중 수): 특등사수 18↑ · 1급 15↑ · 2급 12↑ · 3급 10↑ · 불합격
- 순위: 점수 → 명중 → 쏜 탄 적은 순 → 메인 점수 10/7/5/3/1
- 모든 사로가 같은 순서로 표적이 올라와서 개인 화면 점수(score)를 그대로 비교 가능

## 설정 (`js/config.js`)
표적 수 · 탄알집 크기 · 거리별 표적 크기/서 있는 시간/위치 · 총구 올라가는 속도 · 흔들림 · 반동 · 점수 · 등급 기준 · CPU 실력

## 파일
- js/range.js 표적 순서 · 등급 · 표적 판정 영역
- js/range-view.js 사격장 그림 (하늘 · 산 · 흙둑 · 표적 · 모래주머니 · 가늠자/가늠쇠 · 탄알)
- js/bot.js CPU 사수 · js/scenes/title|play|result.js 화면
- js/minigame-api.js 결과 전송 (postMessage / CustomEvent / window.RE_MINIGAME_LAST_RESULT)

## 화면 보는 법
- 표적: 사람 모양 실루엣(밝은 테두리) · 100 / 200 / 250m 표지판 모두 표시
- 조준: 작은 가늠자 링(점선이라 뒤가 비쳐 보임) + 가늠쇠 기둥 끝 = 맞는 곳
- 사로 위 하늘에 `명중!` / `2연속!` / `빗나감` (어두운 띠 위 글자)
- 사로 아래 정보줄: 탄알집에 남은 탄 · 예비 탄알집 · `명중 N`
- 그 아래 기록판: 표적 20개 — 초록 맞힘 · 빨강 놓침 · 노랑 깜빡 지금 표적
- 맨 아래: 사람은 조작키, CPU는 엎드려 쏴 모습 (쏠 때 총구 불꽃)
- 명중하면 표적이 뒤로 넘어가며 흙먼지 + 사로 화면 흔들림, 연속 명중은 `N연속!`
