# 잭팟 탁구왕 (PING PONG JACKPOT) — RE:ROLL 미니게임

> 3점 먼저! 탁구 토너먼트 최후의 1인은 누구?
> 마법사 성 카지노 홀의 탁구대에서 럼블·나르·꽥스·볼리베어·에코가 1:1 토너먼트를 벌입니다.

## 실행 방법
1. VS Code로 이 폴더를 엽니다.
2. `index.html`을 Chrome이나 Edge로 엽니다. Live Server로 열어도 됩니다.
3. 첫 키를 누르는 순간부터 소리가 납니다.

## 경기 규칙
- **3점을 먼저 내면 승리**합니다. **2:2 듀스**부터는 2점 차가 나야 이기고(듀스 중엔 서브 1점마다 교대), 6점을 먼저 내면 무조건 이깁니다.
- **서브 (진짜 탁구 규칙)**: 치기 키를 누르면 공을 위로 토스하고, 내려올 때 라켓으로 칩니다. 공은 **내 코트에 먼저 한 번 튄 뒤** 네트를 넘어 상대 코트에 튀어야 합니다. 상대 코트에 바로 떨어지거나 내 코트에 두 번 튀면 서브 실수입니다.
- 서브권은 2점마다 바뀝니다(듀스에서는 1점마다). 서브를 안 넣으면 4초 뒤 자동으로 넣습니다.
- 공은 내 코트에 **한 번 튄 뒤** 쳐야 합니다.
- 득점:
  - 상대 코트에 두 번 튀거나 상대가 못 받으면 → 친 사람 득점
  - 네트에 걸리거나 상대 코트에 안 떨어지고 나가면 → 받는 사람 득점

## 조작 (키 3개, 경기 중 화면 아래에 뜻과 함께 항상 표시)
| 플레이어 | 키 |
|---|---|
| P1 럼블 | Q W E |
| P2 나르 | R T Y |
| P3 꽥스 | U I O |
| P4 볼리베어 | Z X C |
| P5 에코 | ← ↑ → |
| 개인 화면 | ← / → 이동, Space 치기 |

| 동작 | 방법 | 특징 |
|---|---|---|
| 전진 / 후진 | 탁구대 쪽 키 / 반대쪽 키 | 공이 떨어질 곳으로 미리 가 있기 |
| **드라이브** | 치기 키 톡 | 빠르고 낮게 |
| **스매시** | 치기 키 꾹 → 떼기 (라켓이 금색으로 빛나면 준비 완료) | 아주 빠름. 타이밍이 나쁘면 네트에 걸림. 높게 뜬 노란 **찬스볼**에 노리기 |
| **드롭** | 전진키 누른 채 톡 | 짧게 떨어져서 상대가 탁구대에 바짝 붙어야 받음 |
| **로브** | 후진키 누른 채 톡 | 높고 깊게 (시간 벌기) |

- 공은 상대 코트에 튄 뒤 **탁구대 끝 근처에서 치기 좋은 높이**로 내려옵니다. 휘두르는 동안 공이 라켓 한가운데에 가장 가까워지는 순간 맞습니다.
- 공이 라켓 한가운데 올 때 치면 **나이스!**: 더 빠르고 낮은 공이 나갑니다. 타이밍이 애매하면 가끔 아웃되고, 아주 나쁘면 공이 높게 뜨는 찬스볼이 됩니다.
- P / Esc: 일시정지, M: 소리 끄기/켜기

## 토너먼트 (방 코드 없음, 대진은 매번 무작위)
| 인원 | 대진 |
|---|---|
| 5명 | 예선 → 4강 2경기 → 3·4위전 → 결승 |
| 4명 | 4강 2경기 → 3·4위전 → 결승 |
| 3명 | 예선 → 결승 |
| 2명 | 결승 |

- 모든 순위(1~5위)가 경기 결과로 정해집니다.
- 메인 게임에 넘기는 순위 점수: 1위 10 / 2위 7 / 3위 5 / 4위 3 / 5위 1
- **개인 화면 모드**는 CPU 3연전입니다(점점 강해짐, 지면 그 자리에서 끝). 점수는 승리 +100, 딴 점수 1점마다 +10, 상대를 1점 이하로 막으면 +50이고, 이 점수로 다른 사람과 비교합니다.

### 대진 정하기 (대진을 무작위로 정해 놓지 않음)
- 토너먼트를 시작하면 먼저 **대진 정하기** 화면이 나옵니다. 아래에서 위로 올라가는 대진표에 선수들이 들어가 있습니다.
- ← → 로 선수 칸을 고르고 Space, 바꿀 칸을 고르고 다시 Space → 두 선수 자리가 바뀝니다.
- ↓ 로 아래 버튼: **섞기**(무작위) / **시작!**
- 경기 사이 대진표도 같은 나무 그림입니다. 이긴 선수의 길이 금색 선으로 위로 올라가고, 진 선수는 회색이 됩니다.
- 메인 게임에서 URL로 바로 시작할 때: `seeds=random`(무작위) 또는 `seeds=3,1,2,5,4`(그 순서, 캐릭터 번호 1~5)를 주면 이 화면을 건너뜁니다.

## 메인 게임 연동
- URL 실행: `index.html?mode=tournament&players=5&autostart=1&embed=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코)
- 결과 받기 (셋 중 아무거나):
  - `window.addEventListener('re-minigame:finish', e => e.detail)`
  - iframe이면 부모 창에서 `message` 이벤트를 받습니다(`type: 'RE_MINIGAME_RESULT'`).
  - `window.RE_MINIGAME_LAST_RESULT`
- `ranking: [{ playerId, slot, name, score, placement, wins, scored, conceded, rank, rankPoints }]`
- `&autoplay=1`: 모든 경기를 CPU끼리 진행합니다(시연·테스트용).

## 파일 구조
```
pingpong-jackpot/
├─ index.html · css/style.css · assets/(fonts, characters) · examples/host-example.html
└─ js/
   ├─ config.js       탁구대 크기, 샷 속도·깊이, 점수 규칙 등 모든 수치
   ├─ ball.js         공 물리 (중력, 탁구대·네트·바닥 충돌)
   ├─ paddler.js      선수 (이동, 드라이브·스매시·드롭·로브, 라켓 동작)
   ├─ ai.js           CPU (공 낙하 지점 예측)
   ├─ match.js        한 경기 (서브, 득점 규칙, 듀스, 점수판, 조작키 표시)
   ├─ hall.js         패럴랙스 카지노 홀(성벽, 슬롯머신, 공을 눈으로 쫓는 관중, 샹들리에) + 탁구대
   ├─ tournament.js   대진표 / 개인 화면 3연전
   ├─ minigame-api.js 메인 게임 연동
   ├─ 공용 엔진: palette · characters · sprites · font · ui · input · audio · particles · transition · game · main
   └─ scenes/ title.js · tournament.js · result.js
```

## 이번 손질
- 경기 3점 선승(2:2부터 듀스) + CPU는 랠리가 길어질수록 실수 ↑ → 5인 토너먼트가 전보다 크게 짧아짐
- 탁구대를 넓히고(128 → 144px) 경기장을 아래로 내려 경기 영역을 넓게, 배경은 위쪽만
- 공 5×5로 키움 · 짧은 꼬리 · 낮을수록 진해지는 그림자 / 스매시는 불꽃 꼬리
- 칠 때마다 작은 고리, 스매시는 번쩍 고리 + 흔들림 + 잠깐 슬로모션
- 점수판 아래 띠: 매치포인트 · 랠리 카운터(6랠리마다 관중 환호)
- 서브 안내는 어두운 띠 위에 (샹들리에와 안 겹침), 이름에서 P번호 뺌, 서브권은 금색 꼬리표
- 토너먼트 경기 중 왼쪽 위 '대기' 선수 얼굴 · 오른쪽 위 '다음: 4강 2' 표시
- 타이틀 키·이름 뒤 어두운 띠, 대진 정하기 배경 어둡게
