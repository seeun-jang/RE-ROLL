# 잭팟 그루브 (JACKPOT GROOVE) — RE:ROLL 미니게임

> 마법사 성 카지노 리듬 배틀! 3키로 박자를 맞춰라
> 마법사 성 카지노의 디스코 무대. 럼블·나르·꽥스·볼리베어·에코가 같은 곡을 동시에 연주하고 점수로 순위를 가립니다.

## 실행 방법
1. VS Code로 이 폴더를 엽니다.
2. `index.html`을 더블클릭해서 Chrome이나 Edge로 엽니다. Live Server로 열어도 됩니다.
3. 첫 키를 누르는 순간부터 소리가 납니다. 리듬게임이라 소리를 켜고 하는 것을 권장합니다.

## 곡 3개 (타이틀 '곡' 줄에서 ← → · 고르면 배경음도 그 곡 코러스로)
| 곡 | 분위기 | BPM | 길이 |
|---|---|---|---|
| 잭팟 그루브 | A단조 카지노 펑크 | 128 | 약 71초 |
| 달빛 칩스 | D단조 밤 라운지 (느긋함) | 96 | 약 65초 |
| 네온 러시 | E단조 유로비트 (빠름) | 150 | 약 61초 |
- 세 곡 모두 이 게임을 위해 만든 오리지널 곡 · 채보는 멜로디에서 자동 생성 (같은 곡 · 난이도면 언제나 같은 채보)

## 모드 (방 코드 없음)
| 모드 | 설명 |
|---|---|
| 함께 하기 | 한 화면에 2~5명. 각자 레인 3개로 같은 곡을 동시에 연주합니다. |
| 개인 화면 | 각자 자기 화면에서 혼자 연주합니다. 같은 곡에 같은 채보라서 점수를 그대로 비교하면 됩니다. |

## 조작 (키 3개 = 레인 3개, 판정선 키캡에 항상 표시)
| 플레이어 | 왼쪽 · 가운데 · 오른쪽 |
|---|---|
| P1 럼블 | Q · W · E |
| P2 나르 | R · T · Y |
| P3 꽥스 | U · I · O |
| P4 볼리베어 | Z · X · C |
| P5 에코 | ← · ↑ · → |
| 개인 화면 | ← ↑ → 또는 A S D (본인 키도 가능) |
| 게임패드 N번 = PN | 왼쪽: 십자키← / X · 가운데: 십자키↑ / A · 오른쪽: 십자키→ / B |

- 떨어지는 칩이 아래 키캡에 닿는 순간 누릅니다.
- **롱노트**(꼬리 달린 칩)는 끝까지 꾹 누릅니다. 일찍 떼면 꼬리가 MISS입니다.
- **P / Esc**: 일시정지 (계속하기를 누르면 3·2·1 후 재개). **M**: 소리 끄기/켜기.

## 난이도
| 난이도 | 노트 수 | 특징 |
|---|---|---|
| 쉬움 ★ | 102 | 박자(4분음표)마다만, 노트가 가장 느림, 동시치기 없음 |
| 보통 ★★★ | 183 | 8분음표, 코러스 마디 첫 박 동시치기 |
| 어려움 ★★★★★ | 254 | 16분음표, 매 박 동시치기, 빠른 속도 |

## 노트 속도
- 타이틀 '속도' 줄 1~5 (3 = 기본, 클수록 빨리 떨어짐) · URL `&speed=1~5`

## 화면
- 인원이 적으면 레인이 넓어지고 노트(칩)도 커짐 (2명이면 큰 칩)
- 콤보는 레인 위 이름 아래, 판정 글자는 판정선 위에 레인 폭에 맞춰 작게 · 둘 다 노트를 가리지 않음
- PERFECT 순간 판정선이 번쩍 + 별빛

## 판정과 점수
| 판정 | 범위 | 점수 비율 |
|---|---|---|
| PERFECT | ±45ms | 100% |
| GREAT | ±90ms | 70% |
| GOOD | ±135ms | 35% |
| MISS | 그 밖 / 놓침 | 0%, 콤보 끊김 |

- 총점은 **1,000,000점 만점**입니다. 판정 점수 900,000점에 최대 콤보 보너스 100,000점을 더합니다.
- 등급: S 950,000점 이상, A 880,000, B 750,000, C 600,000, D는 그 아래.
- 30콤보부터 **피버**: 레인 테두리와 캐릭터가 금색으로 빛납니다(연출만, 점수는 같음).
- 순위는 점수 → 최대 콤보 → PERFECT 수 순서로 정합니다. 완전히 같으면 공동 순위입니다.
- 순위 점수(메인 게임 누적): 1위 10 / 2위 7 / 3위 5 / 4위 3 / 5위 1.

## 판정은 정확하게
- 키를 누른 **실제 시각**(키 이벤트 타임스탬프)과 **오디오 시계**로 판정합니다. 그래서 화면 프레임이 떨어져도 판정이 밀리지 않습니다.
- 스피커나 블루투스 때문에 늦게 느껴지면 타이틀의 **싱크** 값을 조절하세요(10ms 단위, ±200ms). 판정이 늦게 나오면 +, 빠르게 나오면 −로 맞춥니다. 이 값은 브라우저에 저장됩니다.

## 메인 게임 연동
- URL 실행: `index.html?mode=together&players=5&difficulty=normal&song=groove&speed=3&autostart=1&embed=1` (difficulty = easy / normal / hard · song = groove / moon / neon)
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코)
- 결과 받기 (셋 중 아무거나):
  - `window.addEventListener('re-minigame:finish', e => e.detail)`
  - iframe이면 부모 창에서 `message` 이벤트를 받습니다(`type: 'RE_MINIGAME_RESULT'`).
  - `window.RE_MINIGAME_LAST_RESULT`
- 결과 예시: `ranking: [{ playerId, slot, name, score, grade, maxCombo, perfect, great, good, miss, fullCombo, allPerfect, rank, rankPoints }]`
- `examples/host-example.html`은 누적 점수 합산과 보스전 진출자 결정 예시입니다.
- 시연/테스트용 `&autoplay=1`: 모든 플레이어를 자동 연주로 돌립니다. 실력이 저마다 달라서(가끔 놓치고 타이밍이 흔들림) 점수와 순위가 갈립니다.

## 곡 / 채보 수정
- `js/song.js`의 멜로디 문자열을 고치면 음악과 채보가 함께 바뀝니다. 새 곡은 같은 모양으로 하나 더 만들고 `SONGS` · `SONG_ORDER`에 넣으면 타이틀에 나옵니다. 한 마디는 16칸입니다. `A4`는 음 시작, `-`는 길게, `.`은 쉼표입니다.
- 채보 규칙(레인 배치, 롱노트 길이, 동시치기)은 `js/chart.js`의 `CHART_RULES`에서 바꿉니다.
- 판정 범위, 점수, 등급, 노트 속도 같은 수치는 모두 `js/config.js`에 있습니다.

   ├─ sprites.js / font.js / ui.js / particles.js / transition.js
   ├─ minigame-api.js 메인 게임 연동
   ├─ game.js / main.js
   └─ scenes/ title.js · play.js · result.js
