# 잭팟 인형뽑기 (RE:ROLL 미니게임)

인형뽑기 기계 5대에서 동시에! 코인 8개로 인형을 최대한 많이(높은 점수로) 뽑으면 이김.

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코, 나머지 4대는 CPU)
- 메인 게임 연동: `&embed=1` (결과 화면에서 멈춤) — `examples/host-example.html`
- 시연/테스트: `&autoplay=1` · 인형 배치 고정: `&seed=숫자`

## 조작 (플레이어마다 3키, 화면에 항상 표시)
| 플레이어 | ← | 내리기 | → |
|---|---|---|---|
| 럼블 | Q | W | E |
| 나르 | R | T | Y |
| 꽥스 | U | I | O |
| 볼리베어 | Z | X | C |
| 에코 | ← | ↑ | → |
- ←→ : 집게 옮기기 (8초 안에, 지나면 자동으로 내려감)
- 가운데 키 : 집게 내리기 → 자동으로 집고 · 올리고 · 왼쪽 배출구로 옮겨서 놓음
- 개인 화면: ← ↑ → (Space 도 됨) / P 일시정지 · M 소리

## 규칙
- 코인 8개 = 8번 도전. 모든 기계에 **같은 인형이 같은 자리**에 쌓여 있음
- 인형 점수: 캐릭터 인형(곰 · 고양이 · 오리 · 호랑이 · 시바) 10 · 주사위 15 · 칩 5 · **황금곰 30** (기계마다 15개)
- 집는 힘은 매번 다름 (진짜 인형뽑기처럼). **인형 가운데를 집을수록**, 가벼울수록 안 미끄러짐. 황금곰은 무거워서 잘 미끄러짐
- 올라가다 / 옮기다 미끄러지면 떨어짐 — 운 좋으면 배출구로 굴러 들어가기도 함
- n번째 시도의 집는 힘은 모든 기계가 같음 (seed) → 공정
- 순위: 점수 → 뽑은 개수 → 황금곰 수 → 메인 점수 10/7/5/3/1
- 개인 화면은 오늘 날짜로 인형 배치가 정해져서 같은 날엔 모두 같은 기계 → 점수 그대로 비교

## 설정 (`js/config.js`)
코인 수 · 옮기는 시간 · 기계 크기 · 집게 속도 · 집는 힘 범위 · 인형 종류(크기/점수/무게) · 인형 구성 · CPU 실력

## 파일
- js/claw.js 기계 규칙 · 인형 물리 · 집게 상태 (그림과 분리 → Node 에서 시험 가능)
- js/claw-view.js 기계 · 인형 · 집게 · 코인 그림
- js/bot.js CPU 손님 · js/scenes/title|play|result.js 화면
- js/minigame-api.js 결과 전송 (postMessage / CustomEvent / window.RE_MINIGAME_LAST_RESULT)

## 이번 손질
- 인형을 크게 (인형 14px · 주사위 12px · 칩 10px · 황금곰 17px) + 볼터치 · 하이라이트, 집게도 굵고 크게 (집으면 초록 불)
- **버그 수정**: 처음 쌓을 때 인형 일부가 배출구로 빠져 나가던 문제 → 15개 모두 기계 안에서 시작
- 가만히 있는 더미는 배출구로 저절로 굴러 들어가지 않음 (집게가 놓친 인형만 운 좋게 들어갈 수 있음), 칸막이도 높게
- 조준: 집게 아래로 빨간 점선 + 내려갈 곳 그림자
- 표시: 옮기는 남은 시간 '시계 + N초', 코인 '동전 ×N', 배출구 '출구' 팻말 + 아래 화살표, 코인 투입구 'COIN'
- 받침에 뽑은 인형을 줄 세워 보여 줌 (많으면 +N)
- 연출: '집었다!' · '획득! +10' (간판 전구 번쩍), 황금곰이면 JACKPOT 간판 번쩍 + 화면 흔들림. 글자는 작은 꼬리표 위에
- 개인 화면: 내 기계 유리를 2배로 크게 (픽셀 그대로), 오른쪽에 내 점수 · 뽑은 인형 · CPU 4명 기록
- CPU 실력 폭 넓힘 (0.15 ~ 0.9)
