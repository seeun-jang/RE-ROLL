# 잭팟 홈런 더비 (RE:ROLL 미니게임)

한 명씩 타석에 서서 **모두 똑같은 순서의 공**을 쳐서 점수를 겨루는 홈런 더비.
화면은 TV 야구 중계처럼 포수 뒤에서 보는 구도(멀리 마운드의 딜러 투수, 앞에 타자 뒷모습) →
맞으면 높은 곳에서 구장 전체를 내려다보는 타구 화면으로 바뀝니다.

## 화면 (중계 그래픽)
- 왼쪽 위 스코어 박스: 타자 · 남은 기회(야구공 아이콘, 금색 = 잭팟 볼) · LED 점수
- 오른쪽 위 구속판: 공이 나가면 미끄러져 들어옴 (구속 LED + 구종 색 띠)
- 스트라이크 존: 모서리 꺾쇠 + 옅은 3x3 칸
- 하단 바: 조작키 + LED 전광판 (지금 타자 깜빡)
- 타구 화면: 타구 데이터 판 (타구 속도 · 발사각 · 비거리) · 홈런은 화면 가득 빛줄기 + 비거리 카운트업
- 타자는 투수를 바라보는 뒷모습 (캐릭터마다 털 · 모자 · 옷 색 + 럼블 배낭 · 나르 꼬리 · 꽥스 가방끈 · 볼리베어 줄무늬/스카프/꼬리 · 에코 말린 꼬리 · 등번호) / 투수 · 수비수는 딜러 도트
- 타자 소개 화면에서는 캐릭터 앞모습을 크게

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코 / CPU 4명은 같은 공으로 미리 쳐 두고, 내 타석이 끝나면 공개 · 같은 날엔 같은 공)
- 메인 게임 연동: `&embed=1` — `examples/host-example.html`
- 시연/테스트: `&autoplay=1` · 공 순서 고정: `&seed=숫자`

## 조작 (플레이어마다 3키, 화면에 항상 표시 — 자기 차례에만 사용)
| 선수 | ← 배트 | 스윙 | 배트 → |
|---|---|---|---|
| 럼블 | Q | W | E |
| 나르 | R | T | Y |
| 꽥스 | U | I | O |
| 볼리베어 | Z | X | C |
| 에코 | ← | ↑ | → |
- 노란 막대 = 배트가 지나갈 줄. 공이 들어올 줄에 맞춰 두고, 홈 플레이트에 올 때 스윙
- 배트 가운데에 맞을수록 멀리 · 배트가 공 왼쪽이면 땅볼, 오른쪽이면 뜬공
- 일찍 치면 왼쪽(당겨치기), 늦으면 오른쪽(밀어치기) · 45도 넘으면 파울
- 존 밖의 **볼**은 안 치면 기회가 줄지 않음 (선구안!) · **금색 잭팟 볼**은 점수 ×2
- 개인 화면: ← → + Space/↑ · P 일시정지 · M 소리

## 점수
- 홈런 = 비거리(m) 만큼 (보통 100~140) · 3루타 30 · 2루타 20 · 안타 10 · 아웃/파울/헛스윙 0
- 타자당 기회 8번 → 합계 높은 순 (같으면 홈런 수 → 최장 비거리) → 메인 점수 10/7/5/3/1
- 구종 4가지: 직구(빠름) · 슬라이더(늦게 옆으로 휨) · 커브(느리고 크게 떨어짐) · 체인지업(느림)
- 수비수 8명이 떨어지는 곳으로 달려가서, 닿으면 아웃 (같은 타구는 언제나 같은 결과)
- 땅볼: 카메라가 내야로 확대 → 타자가 1루로 달리고, 내야수가 공을 잡아 1루로 송구 (1루수는 베이스 커버, 1루수가 잡으면 직접 밟음) → 공이 먼저 닿으면 **아웃!** / 수비 사이로 빠지면 주자가 먼저 들어가 **세이프!**
