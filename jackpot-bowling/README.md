# 잭팟 볼링 (RE:ROLL 미니게임)

실제 볼링장처럼 **레인 하나에서 5명이 차례대로** 칩니다. 위에는 볼링장 **전광판**(점수표 + 스트라이크 애니메이션), 아래는 볼러 뒤에서 본 레인.

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코, 나머지 4레인은 CPU)
- 메인 게임 연동: `&embed=1` (결과 화면에서 멈춤) — `examples/host-example.html`
- 시연/테스트: `&autoplay=1` (모두 CPU)
- 프레임 수: `&frames=3|5|10` (타이틀 메뉴에서도 선택, 기본 3)

## 조작 (플레이어마다 3키, 화면에 항상 표시)
| 플레이어 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 럼블 | Q | W | E |
| 나르 | R | T | Y |
| 꽥스 | U | I | O |
| 볼리베어 | Z | X | C |
| 에코 | ← | ↑ | → |
- 개인 화면: ← ↑ → (Space/Enter 도 가운데 키)
- P / Esc: 일시정지 · M: 소리

## 볼링장 고증
- 순서: 1프레임 럼블 → 나르 → 꽥스 → 볼리베어 → 에코 → 2프레임 → 3프레임 (한 사람이 자기 프레임을 다 치고 다음 사람)
- 전광판: LANE 번호 · 이름 · 프레임 칸(투구 칸에 X / - 숫자, 아래 누적 점수) · TOTAL, 지금 치는 사람 ▶ 표시
- 전광판 애니메이션: 스트라이크(더블 · 터키 · 포배거 · 파이브배거 …) / 스페어 / 스플릿 / 거터
- 핀 표시판: 서 있는 핀은 밝게, 쓰러진 핀은 어둡게 (오른쪽 패널)
- 피니세터: 1구 뒤 스위퍼가 내려와 쓰러진 핀을 치우고, 프레임이 바뀌면 핀 10개를 새로 세움
- 핀 위 마스킹 유닛 간판, 파울 라인, 조준 화살표 7개, 어프로치 점

## 한 번 던지기
1. **위치**: ←→ 로 공 위치 옮기기 (화살표는 좌우로 흔들림)
2. **방향**: 가운데 키로 화살표 멈추기
3. **힘**: 오른쪽 거터의 힘 게이지가 오르내림 → 가운데 키로 멈추기 (빠를수록 핀이 세게 튐)
4. **스핀**: 굴러가는 동안 ←→ 를 누르면 공이 휨 (왼쪽 막대 = 남은 스핀)

## 규칙
- 3 / 5 / 10프레임 중 선택, 정식 볼링 점수 (스트라이크 = 10 + 다음 2구, 스페어 = 10 + 다음 1구, 마지막 프레임 보너스 투구)
- 1번 핀 살짝 옆(포켓)을 맞히면 스트라이크가 잘 나옴. 정면은 오히려 핀이 남기 쉬움
- 연속 스트라이크: 더블 → 터키 → N연속
- 가끔(25%) 금색 **잭팟 핀**이 섞여 나옴 → 쓰러뜨리면 +3
- 순위: 합계(볼링 + 잭팟) → 스트라이크 수 → 스페어 수 → 메인 점수 10/7/5/3/1
- 개인 화면: 나 + CPU 4명이 같은 레인에서 차례로. 내 점수(score)를 다른 사람과 그대로 비교 가능
- 3프레임 한 판 ≈ 1분 30초 · 5프레임 ≈ 2분 30초 · 10프레임 = 정식 한 게임

## 설정 (`js/config.js`)
프레임 수, 잭팟 핀 확률/보너스, 레인 크기, 화살표 흔들림 속도, 힘 게이지 속도, 공 속도, 스핀 양, CPU 실력

## 파일
- js/bowling.js 핀·공 물리 + 볼링 점수 계산 (Node 에서도 시험 가능)
- js/lane-view.js 레인·핀·공·점수칸·볼링장 배경 그림
- js/bot.js CPU 볼러 · js/scenes/title|play|result.js 화면
- js/minigame-api.js 결과 전송 (postMessage / CustomEvent / window.RE_MINIGAME_LAST_RESULT)

## 이번 손질
- 타이틀 메뉴: 모드 · 인원 · 프레임(3/5/10) · 조준선(켬/끔), 로고 뒤 어두운 띠로 깨짐 해결
- 전광판: 칸이 넓을 때(3·5프레임) 굵은 글씨, 스트라이크는 빨간 칸에 흰 X, 지금 칠 칸 노란 테두리, 인원이 적으면 줄을 높게
- 왼쪽 목록: 얼굴 · 이름 · 점수 (1등 금색)
- 조준선: 공을 잡고 있는 동안 굴러갈 방향을 점선으로 (거터로 가면 빨간 점)
- 타격감: 공이 핀에 가까울수록 구르는 소리가 빨라짐, 핀 맞을 때 화면 흔들림, 스트라이크 때 큰 흔들림 + 꽃가루
- CPU 실력 폭 넓힘 (0.15 ~ 0.9) → 판마다 잘 치는 CPU, 못 치는 CPU 섞임
- 결과 화면: 스트라이크(X) · 스페어(/) · 잭팟 보너스를 한 줄에 넉넉하게
