# 하노마노 (`hanomano`)

같은 과일이 **딱 5개** 보이면 제일 먼저 종을 치는 반응속도 카드게임. 모두가 한 테이블을 같이 본다.
본보기로 삼은 게임: `quiz`(버저 경쟁 · 통신 지연 보정), `mimic`/`mugunghwa`(한 판을 같이 보는 진행).

조작(howTo): **Z: 내 차례에 카드 뒤집기 · Space: 같은 과일이 딱 5개면 종! (틀리면 1장씩 주고 3초 금지) · M: 소리 끄기/켜기**

## 규칙

- 카드 52장(체리 · 레몬 · 라임 · 포도, 과일마다 1개×4 · 2개×3 · 3개×3 · 4개×2 · 5개×1장).
- 차례가 되면 내 카드를 한 장 뒤집어 내 앞에 놓는다. 펼쳐진 카드(각자 맨 위 한 장)의 같은 과일 합이 정확히 5개면 종.
  - 맞으면: 펼쳐진 카드를 전부 가져가고(덱 아래로), 다음 차례는 맞힌 사람.
  - 틀리면: 다른 사람에게 1장씩 주고 3초 동안 종을 못 친다.
- 카드가 0장이어도 탈락하지 않는다. 아무도 뒤집을 카드가 없으면 펼친 카드를 각자 덱으로 되돌린다.
- 제한 시간 2분 30초. 한 명이 카드를 다 가지면 바로 끝.
- 순위: 카드 수 → 종을 맞힌 횟수 → 틀린 횟수가 적은 순. 셋 다 같으면 공동 순위. `score` = 가진 카드 수.
- 걸리는 시간: 하는 법 8초 + 나눠주기 1.5초 + 2분 30초 + 끝 2.5초 + 최종 순위 8초 ≈ 2분 50초.

### 원본과 달라진 점

- **사람끼리만**: CPU(BellBot)와 개인 화면 모드를 없앴다. 2~5명이 각자 PC 에서 하고 판정은 모두 서버(`server/party/games/hanomano/`)가 한다.
- **나눠주기**: 모두 **같은 장수**를 받는다 — 2명 26장 · 3명 17장 · 4명 13장 · 5명 10장. 남는 카드(3명 1장, 5명 2장)는 게임에서 뺀다.
  (원본은 한 장씩 돌려서 3명 · 5명일 때 한 장 더 받는 사람이 있었다.)
- **차례**: 첫 차례는 무작위, 그 뒤로는 들어온 순서(자리 순서)대로 돈다. 뒤집을 카드가 없는 사람은 건너뛴다(원본과 같다).
  화면은 차례 순서를 유지한 채 **내 자리가 항상 아래쪽 첫 자리**에 오도록 돌려서 보여 준다.
- **뒤집기**: 차례인 사람이 자기 키보드의 `Z` 를 누르면 서버가 뒤집는다. 안 누르면 원본의 자동 뒤집기(3초 → 끝날 즈음 1.5초)가 그대로 동작하므로
  가만히 있는 사람 때문에 판이 멈추지 않는다. **연결이 끊긴 사람의 차례는 0.8초 뒤 자동으로 뒤집는다** *(임시 값)*.
  뒤집힌 카드는 서버에서는 바로 펼쳐진 것으로 친다(원본은 8프레임 날아간 뒤 — 화면 연출로만 남겼다).
- **종(통신 지연 보정)**: 브라우저가 누른 시각(서버 시계)을 함께 보낸다. 서버는 도착 시각보다 0.35초 이내로 앞선 시각까지 인정하고,
  처음 종이 도착한 뒤 0.12초 동안 모아서 **누른 시각이 가장 빠른 사람**을 고른다. 판정은 **그 사람이 누른 순간에 펼쳐져 있던 카드**로 한다
  (신호가 가는 사이에 다른 카드가 뒤집혀도 불리하지 않게). 늦게 친 사람은 벌칙이 없다. 연출로 멈춘 동안 누른 종은 무시한다(원본과 같다).
- **멈춤 방지**: 아무도 뒤집을 카드가 없는데 5개가 보이는 채로 5초가 지나면 펼친 카드를 다시 모은다 *(임시 값 — 원본은 계속 기다린다)*.
- **하는 법 화면**: 8초 고정 *(임시 값 — 원본은 15초 또는 아무 키)*. 일시정지 · 타이틀 · 다시 하기는 없다.
- 조작키: 원본의 자리별 키 3개 대신 누구나 `Z`(뒤집기) · `Space`(종).
- 원본의 메인 점수(10/7/5/3/1)와 개인 화면 점수 공식은 쓰지 않는다(판이 `rank` · `score` 로 계산).
- 수치는 `server/party/games/hanomano/config.py` (같은 값이 `web/src/games/hanomano/sim/rules.js`).

## 주고받는 메시지

- 시작 옵션(`client_options`): `rules{TIME_LIMIT, TARGET, FRUITS, TURN_TIME, WRONG_LOCK}`, `flow`(단계별 시간), `order`(차례 순서 = 참가자 id 목록), `each`(처음 카드 수), `spare`(뺀 카드 수), `caster`
- 입력 `game.input.data`
  - `{"k":"flip"}` — 내 차례에 카드 한 장 뒤집기(차례가 아니면 무시)
  - `{"k":"bell","t":누른 시각(서버 시계)}` — 종
- 상태 `game.state`(바뀔 때마다 + 0.5초마다, 모두에게 같은 내용): `phase`(intro/deal/play/collect/wrong/end/final/done), `now`, `since`, `until`, `endAt`, `timeLeft`,
  `turn`(차례인 사람), `turnSince`, `turnTime`(자동 뒤집기까지), `players[{id, deck(장수), pile(장수), show(펼친 카드 위쪽 4장), lock(종 금지가 풀리는 시각), correct, wrong, connected}]`,
  `last`(마지막 종 판정), `end`, `say`, `verdict`, `results`
  - 카드는 `[과일 0~3, 개수 1~5]`. **덱에 남은 카드의 내용은 보내지 않는다**(장수만).
- 사건 `game.event`
  - `{"type":"go"}` — 게임 시작
  - `{"type":"flip","playerId","card","auto","next"}`
  - `{"type":"ring","playerId","ok","text"(판정 설명),"fruit","tops"(누른 순간의 카드),"t"}` + 맞음 `got`, `piles{id: 장수}` / 틀림 `gave`, `to[]`, `near`, `lock`
  - `{"type":"reshuffle"}`, `{"type":"end","reason":"time"|"sweep","playerId","text"}`, `{"type":"final","results"}`
  - `{"type":"say","text","source":"gemini"|"canned","who":"마법사","kind"}`, `{"type":"verdict","headline","mvp","cheer"}`
- `stats`: `cards`(가진 카드), `correct`(종 맞힘), `wrong`(틀림), `got`(종으로 가져간 카드 합)

## AI 가 쓰인 곳

- **판정 설명은 규칙으로 만든다**(원본 `bellReason`): "라임 2+3 = 5개!", "포도 4개뿐! (5개 아님)". AI 가 판정에 관여하지 않는다.
- **AI 해설**(Gemini, `services/caster.py` 의 `LineBook`): 말하는 인물은 카지노 주인 **마법사**. 게임 시작 때 대사 묶음을 한 번 미리 받아 두고,
  상황 10가지 — 시작(`start`) · 종 맞힘(`correct`) · 크게 땀(`bigpot`, 10장 이상) · 틀림(`wrong`) · 4개에서 아깝게 틀림(`near`) · 카드가 3장 이하(`low`) ·
  마지막 1분(`lastMinute`) · 다시 모으기(`reshuffle`) · 시간 종료(`timeup`) · 싹쓸이(`sweep`) — 에 한 줄씩 `say` 로 보낸다(최소 간격 3초).
  화면은 가운데 안내 상자의 판정 설명 **바로 아래 줄**에 보여 주고, AI 가 쓴 줄에는 작은 "AI" 표시를 붙인다. Gemini 가 꺼져 있으면 기본 대사.
- **AI 총평**(`ask_verdict`): 결과가 정해지는 순간 한 번 요청하고, "게임 끝!" · 최종 순위 화면 동안 답이 오면 `verdict` 로 보내 최종 순위 아래 "AI 총평" 칸에 보여 준다.
- 시험용 진행기(`?local`)에는 AI 가 없다 — 기본 대사만 나오고 총평은 없다.
