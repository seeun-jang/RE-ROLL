# 교수님 몰래 댄스! (RE:ROLL 미니게임)

"몰래 춤추기"류 게임을 5명 동시 파티게임으로. 교수님이 칠판에 쓰는 동안만 몰래 춤추고, 돌아보면 얼음!

## 실행
- `index.html` 을 브라우저로 열기 (서버 없이 file:// 로도 동작)
- 바로 시작: `index.html?mode=together&players=5&autostart=1`
- 개인 화면: `index.html?mode=personal&char=3&autostart=1` (char 1~5 = 럼블·나르·꽥스·볼리베어·에코, 나머지 4명은 CPU)
- 메인 게임 연동: `&embed=1` (결과 화면에서 멈춤) — `examples/host-example.html`
- 시연/테스트: `&autoplay=1` · 교수님 움직임 고정: `&seed=숫자`

## 조작 (플레이어마다 3키, 화면에 항상 표시)
| 학생 | 큰 춤 | 작은 춤 | 큰 춤 |
|---|---|---|---|
| 럼블 | Q | W | E |
| 나르 | R | T | Y |
| 꽥스 | U | I | O |
| 볼리베어 | Z | X | C |
| 에코 | ← | ↑ | → |
- 가운데 키 **꾹** = 작은 춤 (초당 6점, 손 떼면 바로 멈춤)
- ← 또는 → **꾹** = 큰 춤 (초당 15점, 대신 손 떼고 자리에 앉기까지 0.23초 동안 계속 보임)
- 개인 화면: ← ↑ → (Space 도 작은 춤) / P 일시정지 · M 소리

## 규칙
- 수업 60초. 교수님: 칠판에 쓰기 → **낌새**(분필 소리 멈춤 · 고개 갸웃 · "흠흠…") → 돌아봄 → 반 둘러보기 → 다시 칠판
- 낌새만 주고 안 돌아보는 **페이크**, 낌새 없이 **갑자기 돌아보기**도 있음 (수업 끝으로 갈수록 자주 · 칠판 쓰는 시간도 짧아짐)
- 돌아봤을 때 춤추고 있으면 **딱 걸림**: -20점, 피버 초기화, 2.5초 벌서기 (손 들고). 3번 걸리면 **복도행** (남은 수업 동안 못 춤)
- 춤추다가 교수님이 돌아볼 때 얌전히 버티면 **피버** ×1 → ×1.5 → ×2 → ×3 (점수 배수)
- 순위: 점수 → 덜 걸린 순 → 최고 피버 → 메인 점수 10/7/5/3/1
- 개인 화면은 오늘 날짜로 교수님 움직임이 정해져서 같은 날엔 모두 같은 수업 → 점수 그대로 비교

## 설정 (`js/config.js`)
수업 시간 · 춤 점수 · 큰 춤 멈추는 시간 · 피버 배수 · 벌점/벌서기 · 교수님(쓰는 시간·낌새·돌아보는 속도·페이크·갑자기 확률) · CPU 실력

## 파일
- js/teacher.js 교수님 AI (seed 로 움직임 고정)
- js/class-view.js 교실 · 칠판 글씨 · 시계 · 교수님(뒷모습/앞모습/돌아보기) · 책상 명패 · 학생 춤/벌서기
- js/bot.js CPU 학생 · js/scenes/title|play|result.js 화면
- js/minigame-api.js 결과 전송 (postMessage / CustomEvent / window.RE_MINIGAME_LAST_RESULT)

## 이번 손질
- 교수님 새 그림: 흰머리 · 둥근 안경 · 수염 · 트위드 재킷(팔꿈치 덧댐) · 나비넥타이 / 뒷모습 → 옆모습 → 앞모습으로 돌아봄
- 낌새: 분필 가루가 멈추고 머리 위 '?' 깜빡 + 긴장선 + '흠흠…' 말풍선, 배경음이 뚝 줄어듦
- 반을 볼 때: 교실이 어두워지고 교수님 눈빛(조명)이 학생들을 훑음 → 걸리면 그 학생에게 멈춤
- 춤: 작은 춤 = 앉아서 들썩 / 큰 춤 = 벌떡 일어나 점프 + 찌그러졌다 늘어남 + 효과선
- 걸림: 두 손 번쩍 + 머리 위 빨간 '!' (회색 덩어리 없앰), 글자는 어두운 꼬리표 위에
- 책상: 명패 숫자 크게 · 경고 카드(노랑 · 노랑 · 빨강) 크게 · 피버 배수 꼬리표
- 복도행: 걸어서 교실 밖으로 나가고 자리에 '복도' 팻말
- 결과 화면에 '걸린 횟수 · 최고 피버' 칸 이름
