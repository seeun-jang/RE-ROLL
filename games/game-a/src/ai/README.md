# PFC · AI 기능 확장 계획

지금은 키보드로 규칙과 연출을 완성한 단계입니다. 아래 기능은 이후 단계에서 붙일 수 있도록 연결 위치만 정리합니다.
**API 키는 절대 코드에 넣지 말고** `.env`(이미 .gitignore 처리됨)나 서버를 거쳐 사용하세요.

## 1. 웹캠 자세 인식으로 싸우기 (3단계, 핵심)

- 기술: MediaPipe `@mediapipe/tasks-vision` PoseLandmarker (`numPoses: 2`, 브라우저에서 실행)
- 화면 왼쪽 사람 = P1(student), 오른쪽 사람 = P2(교수)
- student: 주먹 뻗기 → 공격, 무릎 들기 → 기술, 숙이기 → 구르기 / 교수: 손바닥 내밀기 → 공격, 두 손 모아 밀기 → 파이어볼, 한 손 하늘로 → 낙뢰
- 연결 위치: `src/input/motionInput.js`를 만들어 `actions.js` 형식으로 돌려주면 끝 (`inputSources`로 전달)
- 게임에 주는 영향: 교수 역은 "주문 동작"을, student 역은 "격투 동작"을 몸으로 하게 되어 역할 차이가 확실해짐

## 2. 음성 주문 (STT) — 교수 전용

- "파이어볼!", "번개!", "메테오!"처럼 주문을 외치면 해당 마법이 나감 (Web Speech API 또는 Hugging Face Whisper)
- 게임에 주는 영향: 마법사다운 플레이. 마이크 하나로도 교수 쪽 주문만 인식하면 되어 구현이 쉬움
- 밸런스: 음성은 느리므로 음성 주문은 마나를 10% 덜 쓰게 하는 식으로 보상

## 3. AI 해설 캐스터 (생성형 AI + TTS)

- 엔진 사건(파이어볼 명중, 구르기로 회피, 메테오, 백호 난무)을 라운드마다 요약해 LLM에 보내 짧은 중계 멘트 생성
- 연결 위치: `FightScreen.jsx`에서 `takeEvents()`로 꺼낸 사건을 모으기, 라운드 종료 배너 아래에 표시
- 게임에 주는 영향: 규칙은 그대로, 몰입감 강화. 키는 서버(프록시)를 통해서만 사용
