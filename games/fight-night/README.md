# 매직 파이트 나이트 (MAGIC FIGHT NIGHT) — RE:ROLL 미니게임

> 마법성 카지노 복싱 토너먼트! 최후의 1인은 누구?
> 마법사 성 지하 카지노의 특설 링. 동물 5명이 1:1 토너먼트로 챔피언을 가립니다.

## 실행 방법
1. VS Code로 이 폴더를 엽니다.
2. `index.html`을 더블클릭해서 Chrome이나 Edge로 엽니다. Live Server로 열어도 됩니다.
3. 첫 키를 누르는 순간부터 소리가 납니다.

## 토너먼트 진행 (방 코드 없음, 대진은 직접 정하거나 무작위)
| 인원 | 대진 | 순위 결정 |
|---|---|---|
| 5명 | 예선 → 준결승 2경기 → 3·4위전 → 결승 (대진은 시작 전에 직접 정함) | 우승 1위, 준우승 2위, 3·4위전 승자 3위, 패자 4위, 예선 패자 5위 |
| 4명 | 준결승 2경기 → 3·4위전 → 결승 | 1~4위 |
| 3명 | 예선 → 결승 | 1~3위 |
| 2명 | 결승 | 1~2위 |

- 경기 사이에 **대진표**가 나오고, 다음 경기가 강조됩니다. Space를 누르면 시작합니다.
- 한 경기는 **45초**입니다. KO가 나오면 바로 끝나고, 시간이 끝나면 남은 체력으로 판정합니다(같으면 맞힌 횟수).
- 개인 화면 모드는 **CPU 3연전**입니다. 이기면 +100, KO 승은 +50, 남은 체력 1당 +1이고, 지면 그 자리에서 끝납니다. 이 점수로 비교합니다.

## 조작 (키 4개, 경기 중 화면 아래에 항상 표시)
| 동작 | 방법 |
|---|---|
| 앞으로 | 상대 쪽 키 |
| 대시 | 상대 쪽 키 빠르게 톡톡 (짧은 간격 안에 두 번 — 실수로 안 나가게 좁힘) |
| 뒤로 | 상대 반대쪽 키 (앞걸음과 같은 속도 · 막지는 않음) |
| 가드 | 가드 키 꾹 (제자리에서 막음 · 피해 15%로 줄임) |
| 슥빡 카운터 | 펀치가 닿기 직전에 가드 키 → 슥 피함 → 바로 펀치 = 카운터 (피해 2배) |
| 잽 | 펀치 키 톡 |
| 강펀치 (어퍼컷) | 펀치 키 꾹 → 떼기 (글러브가 금색으로 빛나면 준비 완료 · 꾹 누르는 동안에도 앞뒤로 걸을 수 있음) |

| 플레이어 | 왼쪽 | 펀치 | 오른쪽 | 가드 |
|---|---|---|---|---|
| P1 럼블 | Q | W | E | S |
| P2 나르 | R | T | Y | G |
| P3 꽥스 | U | I | O | K |
| P4 볼리베어 | Z | X | C | V |
| P5 에코 | ← | ↑ | → | ↓ |

- 화면 아래 조작 바에는 두 선수의 키캡이 나오고, 지금 서 있는 방향에 맞춰 **"앞 / 펀치 / 가드"** 뜻이 바뀌어 표시됩니다.
- 개인 화면 모드: `←`/`→` 이동 + `Space` 펀치 + `↓` 가드 (자기 키도 됨)
- 게임패드 지원, `P`/`Esc` 일시정지, `M` 소리 켜기/끄기

## 중계 연출 (업데이트)
- **선수 1.25배 크기 + 넓힌 링**: 펀치가 잘 보이면서도 링이 답답하지 않게 (거리 · 속도 수치도 같은 배율로 맞춤)
- **캐릭터 손에 낀 글러브**: 그림 속 원래 손 자리에 글러브를 끼움 (원래 손은 지움) · 펀치 · 가드 때 그림과 같은 소매 · 털 색의 팔이 소매 끝에서 뻗어 나감 · 잽은 당겼다가 튀어나가듯 쭉(주먹이 눕혀짐) → 감속하며 돌아옴 · 어퍼컷은 배에서 호를 그리며 턱까지 · 가드는 두 글러브를 얼굴 앞으로 바짝 올리고 웅크림(막으면 글러브가 덜덜) · 펀치하는 선수가 앞에 그려짐
- **슥빡 카운터**: 상대 펀치가 닿기 직전(8프레임 안)에 가드 키 = 슥! 잔상을 남기고 피함 → 헛친 상대는 비틀 → 40프레임 안에 펀치를 맞히면 빡! 카운터 (피해 2배) · 카운터 찬스 동안 글러브가 금색으로 깜빡
- **뒷걸음 = 앞걸음 속도**
- **대진 직접 정하기**: 토너먼트 시작 전 ← → 로 칸을 고르고 Space 로 두 명을 차례로 골라 자리 바꾸기 · [무작위] · [확정!] (R = 무작위)
- **대진표 나무**: 아래 줄 선수 → 위로 올라가며 경기 마디 → 맨 위 트로피. 이긴 길은 금색, 진 선수는 회색, 다음 경기 깜빡, 3·4위전은 왼쪽 위 작은 칸
- **중계 HUD**: 얼굴 아이콘 · 굵은 체력바(눈금 · 숫자) · 가운데 큰 시계
- **조작 바**: 큰 키캡 + 지금 뜻(앞 / 펀치 / 가드)을 색으로 표시 (빨강 앞 · 금색 펀치 · 파랑 가드)
- **링 아나운서**: 홍코너 · 청코너 선수 소개 자막 → 라운드 이름 → 땡! → FIGHT!
- **KO 카운트**: 심판이 다가와 1~10 카운트 → 땡땡 → 빛줄기와 함께 K.O.!
- **챔피언 시상**: 결과 화면에서 우승자가 챔피언 벨트를 차고 왕관 (개인 화면은 3연승하면 벨트)
- 시연/테스트: `&autoplay=1` (모든 경기를 CPU끼리)

## 부드러운 움직임
- **가속·감속**: 키를 누르면 서서히 빨라지고, 떼면 미끄러지듯 멈춥니다.
- **보간 그리기**: 게임 로직은 60FPS로 고정하고, 화면은 직전 프레임과 사이를 이어 그립니다. 120Hz·144Hz 모니터에서도 끊기지 않습니다. 최종 좌표는 정수로 맞춥니다.
- **글러브 애니메이션**: 글러브가 목표 위치를 부드럽게 따라가서 잽은 쭉 뻗었다 돌아오고, 강펀치는 아래에서 위로 휘두릅니다.
- **몸 기울기와 걸음 리듬**: 걷기·펀치·가드·피격에 따라 몸이 부드럽게 기울고, 걸을 때 통통 튑니다.
- **체력바**: 깎인 부분이 흰색으로 남았다가 천천히 줄어듭니다.
- **손맛**: 히트 스톱, 화면 흔들림, 불꽃, KO 슬로모션, 관중이 크게 들썩임

## 메인 게임 연동
```
index.html?mode=tournament&players=5&autostart=1&embed=1
index.html?mode=personal&char=3&autostart=1&embed=1
```
- 결과 받기: iframe `message`(type `RE_MINIGAME_RESULT`) / `re-minigame:finish` 이벤트 / `window.RE_MINIGAME_LAST_RESULT`
- 결과 형식:
```json
{
  "gameId": "fight-night",
  "mode": "tournament",
  "ranking": [
    { "playerId": "duck", "slot": 3, "name": "꽥스", "placement": 1, "score": 670, "wins": 2, "kos": 0, "damage": 170, "rank": 1, "rankPoints": 10 }
  ]
}
```
- 토너먼트는 `placement`(최종 순위)가 그대로 `rank`입니다. 개인 화면은 `score`로 비교합니다. 메인 점수는 10/7/5/3/1입니다.
- `examples/host-example.html`: iframe으로 띄우고 누적 점수를 합산하는 예시

## 파일 구조
```
fight-night/
├── index.html, README.md
├── css/style.css
├── assets/fonts/              Galmuri 픽셀 폰트 (SIL OFL)
├── assets/characters/         캐릭터 PNG (보내준 그림) + 얼굴 아이콘용 작은 그림
├── examples/host-example.html 메인 게임 연동 예시
└── js/
    ├── config.js        모든 수치 (이동, 펀치, 가드, 경기 시간, 점수, 키 배치)
    ├── palette.js       32색 팔레트
    ├── characters.js    동물 5종
    ├── sprites.js       캐릭터 PNG 불러오기 + 글러브 도트
    ├── font.js          3x5 비트맵 폰트
    ├── input.js         키보드 + 게임패드
    ├── audio.js         칩튠 효과음 (잽, 강펀치, 가드, 공 울림, KO) + BGM
    ├── particles.js     파티클
    ├── ui.js            한글 픽셀 글씨 (굵은 12px · 큰 제목 15px · 작은 10px), 패널, 버튼
    ├── hud.js           카드 · 디더 무늬
    ├── ui-broadcast.js  중계 패널 · 자막 띠 · 빛줄기
    ├── transition.js    디더 페이드 / 원형 와이프
    ├── ring.js          링 + 관중석 (패럴랙스 3레이어)
    ├── fighter.js       복서 (이동, 대시, 가드, 잽/강펀치, 피격, KO, 보간 그리기)
    ├── ai.js            CPU 복서 (개인 화면 3연전)
    ├── bout.js          1:1 한 경기 (판정, 손맛 연출, HUD, 조작 바)
    ├── tournament.js    토너먼트 대진 + CPU 3연전
    ├── minigame-api.js  결과 산출 + 메인 게임 전송
    ├── scenes/title.js       타이틀 (모드, 인원 — 방 코드 없음)
    ├── scenes/tournament.js  대진표 → 경기 → … (일시정지 포함)
    ├── scenes/result.js      최종 순위 (클리어)
    ├── game.js          메인 루프 (보간 그리기)
    └── main.js          시작점 + URL 옵션
```
