# 잭팟 인형뽑기 (`claw`)

원본: `claw-jackpot` (한 키보드로 기계 5대, CPU 손님). 본보기로 삼은 기존 게임: `garden`(참가자마다 판 하나를 서버가 60분의 1초 단위로 진행).

조작 설명 한 줄(howTo): **←/→(A/D): 집게 옮기기 · Space(↑/↓): 집게 내리기 (8초가 지나면 저절로 내려감) · M: 소리 끄기/켜기**

## 규칙

- 각자 자기 화면의 기계에서 **코인 8개 = 8번 도전**. 모든 기계에 **같은 인형 13개가 같은 자리**에 쌓여 있다(시작할 때 서버가 seed 하나를 정한다).
- 한 번의 도전: 집게를 좌우로 옮기고(8초 안에, 지나면 자동) 내리면 → 자동으로 집고 · 올리고 · 왼쪽 배출구로 옮겨서 놓는다.
- 인형 점수: 캐릭터 인형(곰 · 고양이 · 오리 · 호랑이 · 시바) 10 · 주사위 15 · 칩 5 · 황금곰 30.
- 집는 힘은 시도마다 다르고(n번째 시도의 힘은 모든 기계가 같다), 인형 가운데를 집을수록 · 가벼울수록 안 미끄러진다. 황금곰은 무거워서 잘 미끄러진다. 놓친 인형이 운 좋게 배출구로 굴러 들어가기도 한다.
- 모두가 코인을 다 쓰면 끝. **순위: 점수 → 뽑은 개수 → 황금곰 수**(모두 같으면 공동 순위).
- 숫자(기계 크기 · 집게 속도 · 집는 힘 · 인형 크기/점수/무게 · 인형 구성)는 원본 `js/config.js` 값 그대로이고 `server/party/games/claw/config.py` 에 있다(같은 값이 `web/src/games/claw/sim/config.js` 에 있고 테스트가 비교한다).

### 원본과 달라진 점

- 한 키보드로 기계 5대 → **각자 PC 에서 자기 기계 하나**. CPU 손님은 없다(시험용 봇은 `sim/` 안에만 있다).
- **판정은 서버가 한다**: 참가자마다 기계(`machine.py`, 원본 `claw.js` 를 Python 으로 옮긴 것)를 서버가 60분의 1초 단위로 진행한다. 브라우저는 "누르고 있는 방향 / 내리기" 만 보내고, 서버가 보내 주는 기계 상태를 그린다. 입력이 도착하면 그 시각까지 기계를 진행한 뒤 반영한다.
- 내 집게의 **좌우 이동만** 기다리지 않고 바로 보여 준다(예측). 멈추면 서버 위치로 맞춘다. 무엇을 집었는지 · 점수는 서버 상태만 쓴다.
- 화면은 원본의 **'개인 화면'**(내 기계 유리를 2배로, 오른쪽에 내 점수 · 뽑은 인형 · 다른 사람 기록)을 쓴다. 기계 5대를 나란히 보여 주는 화면은 없다.
- 코인을 먼저 다 쓴 사람은 아직 하는 사람의 기계를 **관전**한다.
- 조작 키를 한 가지로 통일: ←/→(A/D), Space(↑/↓).
- 시작 전 설명 화면 4초 *(임시 값 — 원본은 100프레임)*. 끝나면 '영업 종료!' 2.5초(원본 150프레임, 이 동안 굴러가던 인형도 마저 센다) → 최종 결과 화면 8초.
- 원본의 메인 점수(10/7/5/3/1)는 뺐다(포인트 환산은 보드가 정한다). 일시정지 · 타이틀 · 다시 하기도 없다.
- 거리 계산을 `Math.hypot` 대신 `sqrt(dx² + dy²)` 로 바꿨다(서버 Python 과 브라우저 JS 가 소수점 끝자리까지 같은 값을 내도록). 결과 차이는 사실상 없다.
- 연결이 끊긴 사람은 키에서 손을 뗀 것으로 본다. 8초마다 집게가 저절로 내려가므로 게임은 끝까지 간다(한 판 최대 약 2분).

## 주고받는 메시지

- 시작 옵션(`client_options`): `seed`, `coins`, `moveTime`(프레임), `intro`, `endDelay`, `final`, `types`(인형 종류 이름 배열), `prizes{종류:{r,value}}`, `caster`
- 입력: `{"k":"in","dir":-1|0|1}` — 누르고 있는 방향이 바뀔 때마다 / `{"k":"in","dir":…,"drop":true}` — 내리기 키를 누른 순간(코인을 넣고 8프레임 안이면 원본처럼 무시)
- 상태(초당 30번, 참가자마다 따로): `phase`(intro/play/end/final/done), `now`, `startAt`, `players{id:{score,coins,done,won[종류 번호]}}`, `results`(final 부터), `verdict`(AI 총평, 없으면 null), 그리고
  - `me`: 내 기계 — `frame`, `coins`, `score`, `dir`, `claw{x,y,open,state,t,grab(잡은 인형 id, 없으면 -1)}`, `prizes[[id, 종류 번호, x, y], …]`, `won[종류 번호]`
    - `claw.state`: idle → move → drop → close → lift → carry → open → back
  - `watch{id, view}`: 내가 코인을 다 썼을 때만. 아직 하는 사람의 기계(`view` 는 `me` 와 같은 모양)
- 사건(기계 사건은 본인에게만): `{"type":"coin","left"}`, `{"type":"drop"}`, `{"type":"grab","id","prize"}`, `{"type":"miss"}`, `{"type":"slip","id","prize"}`, `{"type":"won","id","prize","value","lucky","score"}`
- 사건(모두에게): `{"type":"say","kind","text","source":"gemini"|"canned","who":"꽥대장"}`, `{"type":"verdict","headline","mvp","cheer"}`
- `stats`: `prizes`(뽑은 개수), `gold`(황금곰 수), `won`(뽑은 인형 종류 목록), `tries`, `grabs`(집은 횟수), `slips`(미끄러진 횟수)

## AI 가 쓰인 곳 (서버의 Gemini, `services/caster.py`)

- **해설 대사**: `start()` 에서 `LineBook` 으로 이 판에 쓸 대사 묶음을 한 번 받아 둔다. 말하는 인물은 **꽥대장**(오락실 사장 노릇을 하는 수다쟁이 오리).
  상황 9가지 — `start`(시작) · `gold`(황금곰 획득) · `win`(인형 획득) · `lucky`(놓친 인형이 굴러 들어감) · `miss`(헛손질) · `slip`(미끄러짐) · `lastcoin`(마지막 코인) · `lead`(1등이 바뀜) · `end`(우승).
  최소 간격 3초(황금곰 · 역전 · 시작 · 끝은 1초). 화면은 오른쪽 정보판의 점수 안내 자리에 자막으로 보여 주고, AI 가 쓴 줄에는 작은 "AI" 표시가 붙는다.
- **총평**: 결과가 정해지는 순간(`end` → `final`) `ask_verdict` 를 한 번 요청하고, 결과 화면 8초 동안 도착하면 `verdict` 사건으로 보낸다(상태에도 넣는다). 화면은 최종 순위 아래 "AI 총평" 으로 보여 준다.
- Gemini 가 꺼져 있거나 늦으면 기본 대사(상황마다 2줄)로 진행하고 총평은 보내지 않는다. 게임 진행(tick/on_input) 안에서는 Gemini 를 부르지 않는다.
- 시험용 진행기(`sim/Sim.js`)에는 AI 가 없다: `say` 는 기본 대사만, `verdict` 는 보내지 않는다.

- 화면: `web/src/games/claw/` — `minigame.js`, `net/`(ClawScreen 화면 · NetLink · 원본 그리기/소리 모듈), `sim/`(시험용 진행기 · 규칙 · 숫자), `assets/`(캐릭터 얼굴 PNG · 굵은 Galmuri 글꼴)
